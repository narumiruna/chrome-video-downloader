# Test media fixtures

Every file in this directory is generated locally for this project and contains no third-party media.

`sample.mp4` and `sample.webm` are one-second FFmpeg `testsrc2` patterns.

The HLS and DASH fixtures are generated from `sample.mp4` and are used only to verify unsupported-source behavior.

Regenerate the media with the commands documented in `docs/support-matrix.md`.
